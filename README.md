# 📊 Калькулятор покрытия и переработки

Простой калькулятор для расчёта **итоговой цены тонны профиля** с учётом покрытия (порошковая окраска) и переработки (гибка, резка).

**Работает в паре с:** [lstk-profile-calculator](https://github.com/kilevoy/lstk-profile-calculator) — берёт цену сырья и добавляет стоимость технологий.

---

## ⚡ Задача

Менеджер знает цену сырья (руб/тонна) и хочет быстро получить **итоговую цену** с:
- Порошковой окраской
- Гибкой, резкой
- Доставкой

**Результат:** таблица итоговых цен по всем толщинам.

---

## 🧮 Формула

```
Площадь тонны = (1000 / масса_пм) × (ширина_рулона / 1000) [м²]
Стоимость покрытия = площадь_тонны × цена_покрытия_за_м²

Итоговая цена = Цена_сырья + Стоимость_покрытия + Ставка_переработки
```

## 📊 Сравнение с основным калькулятором

| | `lstk-profile-calculator` | `coating-processing-calculator` |
|---|---|---|
| **Задача** | Какой размер профиля и сколько стоит погонный метр | Сколько стоит тонна с покрытием и переработкой |
| **Вход** | Размеры профиля + цена сырья | Цена сырья + цена покрытия + ставка переработки |

| **Сложность** | 🟠 Средняя (геометрия гибки) | 🟢 Низкая (арифметика) |
